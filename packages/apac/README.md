# @holiday-calendar/apac

APAC (Asia-Pacific) regional holiday calendars for the [Holiday Calendar](https://github.com/holiday-calendar/holiday-calendar-ts) library.

## Status

This package is currently a **scaffold with no calendars implemented yet**.
No holiday calendar codes are exported at this time. Individual APAC
calendars will be added in future issues — see the
[issue tracker](https://github.com/holiday-calendar/holiday-calendar-ts/issues)
for current progress.

If you need a working calendar today, see
[`@holiday-calendar/western`](https://www.npmjs.com/package/@holiday-calendar/western)
(US) or [`@holiday-calendar/core`](https://www.npmjs.com/package/@holiday-calendar/core)
to build your own.

## Installation

```bash
npm install @holiday-calendar/apac @holiday-calendar/core
```
